# CloudRepo Environment Direct package

This Agent Plugins 1.0 package contains two skills and an optional pure planner.
Its GitHub app binding is optional: an installed connector identifies a possible
channel, not proof of write, dispatch, deletion, or authentication capabilities.

Use `cloudrepo-environment-direct` for Root-facing planning and
`github-actions-direct` when GitHub Actions is the selected provider. Read the
linked references only for the active stage. Azure is deliberately contractual
only. The package contains no MCP server and does not execute remote operations.

The offline planner accepts only one bounded static `push` workflow profile:
one job, a known native runner or concrete OS matrix, concrete steps, and one
non-dynamic command. It does not execute that text or claim a CI run passed.
Dynamic, multi-job, malformed, or conflicting workflows require a Root override.
